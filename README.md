# Formula 1 Race Intelligence Analysis

Skill Wallet Data Analytics – Tableau Project.

## Overview
This report delves into Formula 1 Race Intelligence, providing visual exploration of driver performance, team championship trajectories, tyre compound strategies, circuit-level race participation, driver reliability/DNF analysis, and global podium achievements.

## Stakeholder Scenarios Covered
- **Scenario 1: Mr. Arnold (Senior Performance Strategist)**: Benchmarking team championship points against Red Bull & Mercedes, evaluating tyre compound strategies (Soft, Medium, Hard, Intermediate), and analyzing global driver talent pools.
- **Scenario 2: Ms. Lisa (Motorsport Broadcast Analyst)**: Driver performance leaderboards, Grand Prix host country distribution, and podium achievement breakdowns for broadcast infographics.
- **Scenario 3: Mr. Gilchrist (F1 Technical Regulation Analyst)**: Studying DNF (Did Not Finish) patterns (engine, brake, collision, mechanical) across 17 seasons to assess driver reliability and regulatory safety impact.

## Repository Structure
- `data/`: Sample CSV datasets (`driver_performance.csv`, `constructor_standings.csv`, `dnf_reliability.csv`).
- `tableau/`: Tableau workbook configuration.
- `index.html`: Interactive web demo dashboard for GitHub Pages.
